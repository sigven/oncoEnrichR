# Function that validates a particular db object (data.frame) in oncoEnrichR

Function that validates a particular db object (data.frame) in
oncoEnrichR

## Usage

``` r
validate_db_df(df, dbtype = "genedb")
```

## Arguments

- df:

  data.frame with annotation data for oncoEnrichR

- dbtype:

  type of oncoEnrichR datasource
